# Integrate B experiment pipeline with A scanner and final showcase

The complete lab now uses `rsa_audit.scan_keys` for both pairwise and batch detection. The B module converts public input and result formats, reconstructs validated RSA private keys, decrypts OAEP ciphertexts, evaluates results against separate ground truth, and replaces vulnerable keys before rescanning. The A engine and its original animation assets are preserved.

The offline eight-page presentation is entirely in English and combines the existing algorithm animations with newly measured results, saved attack evidence, and repair results. Supplemental dialogs explain private-key reconstruction, control experiments, scan stages and weak prime pools. A separate command runs the complete live Python demo. Dependencies, replay instructions, an English eight-minute speaking guide, benchmark configuration, input hashes, CSV records and figures are included. Full local datasets, ground truth, private PEM exports and environments are excluded from Git. Archived text and its checksums use canonical LF bytes for cross-platform cloning.

Validation: 70 Python tests pass, including the teammate's fixed OAEP challenge through the B recovery module. The 2048-bit demo factors five distinct moduli and verifies six messages, with zero false positives or false negatives. After replacing five keys, the current collection has no detected shared factors. Both algorithms pass ten scans across independent-prime, duplicates-only, isolated-target, shared-prime and repaired controls. Two negative OAEP checks reject a wrong label and modified ciphertext. Twenty-one completed benchmark scans pass factor and OAEP verification. At 3000 unique moduli, batch median is 0.780 seconds; all three pairwise runs exceed the 45-second worker limit and are recorded as timeouts. Existing browser math tests also pass. Performance depends on the supplied workload and machine.
