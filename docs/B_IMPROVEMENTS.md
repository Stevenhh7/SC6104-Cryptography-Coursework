# B 部分的实现与成果优化

依据原始《Possible Crypto projects.pdf》第 4 页对真实尺寸 RSA 攻击的重视，以及第 10 页的技术深度、执行质量、Q&A 和 8 分钟含 demo 要求，整合版保持一个完整项目，补强实验和解释材料。

## 已增加的证据

- `rsa_lab/validation.py` 对五种场景分别运行批量和两两算法，共十次扫描。攻击与恢复只接收复制后的公开文件，评估随后使用真值。
- 正常密钥和仅重复记录的对照，验证不会把重复公钥误当作可分解密钥。
- 从弱集合中单独取出一把目标公钥，验证缺少关联公钥时的检测覆盖限制。
- 修复后的完整集合再次执行两种算法和恢复，区分攻击恢复为零与新密钥的合法加解密成功。
- 错误 OAEP 标签和密文损坏分别验证为拒绝解密。
- 归档使用统一 LF 行尾，保留原始运行输入哈希和归档字节哈希，防止 Windows / Git 换行变换破坏复现。

## 英文展示的 B 页面

性能页采用适合投影的大字号图表，明确中位数、三次观察范围、相同数据与后端，以及超时点的解释。阶段耗时打开独立补充视图，避免主页面过密。

攻击页按公开输入、检测、恢复、独立核验逐步展示。五把不同密钥与六条消息分别统计。核心恢复代码与实际数学检查结果可在 Key reconstruction 中查看。

结论页连接主实验和有限素数池扩展。控制矩阵和扩展实验作为 Q&A 材料，不占用固定八页主线。演讲页面、按钮与主讲稿全部为英文；中文代码详解用于理解和复习。
